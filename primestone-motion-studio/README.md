# Primestone Motion Studio

Application Windows de montage audiovisuel et de Motion Design, local-first. Projet neuf.

Ce dossier est **isolé** du reste du dépôt (`primestone-brand`, bibliothèque de marque web) : aucun code ni document
existant n'est repris. L'emplacement définitif du projet est une décision en attente (`docs/DECISIONS.md`, D-001).

Point d'entrée : `docs/CURRENT_STATE.md`, puis `docs/NEXT_ACTIONS.md`.

| Document | Rôle unique |
|---|---|
| `MASTER_PLAN.md` | Roadmap des 8 phases, registre des risques |
| `CURRENT_STATE.md` | État réel à date : environnement, ce qui existe, bilan validé / non validé / bloqué |
| `PHASE_STATUS.md` | Avancement et critères de sortie par phase |
| `DECISIONS.md` | Journal des décisions (statut, justification, preuve), dont celles en attente d'accord |
| `BLOCKERS.md` | Blocages ouverts et leur condition de levée |
| `ARCHITECTURE.md` | Architecture logique, règles de communication, matrice des technologies |
| `PROTOTYPE_RESULTS.md` | Plan des prototypes et résultats mesurés |
| `TEST_EVIDENCE.md` | Preuves : commandes réellement exécutées et leurs sorties |
| `NEXT_ACTIONS.md` | Prochaines actions ordonnées et justifiées |
| `REQUIREMENTS_TRACEABILITY.md` | Exigences, leur source, leur statut, leur couverture |

# Premiere Pro

Les modèles d'animation (`.mogrt`) seront **exportés par les scripts After Effects** du lot 4 (fonction native `exportAsMotionGraphicsTemplate`). Aucun `.mogrt` n'est livré dans ce lot : un MOGRT ne peut être produit que par After Effects ou Premiere eux-mêmes.

Pour connaître votre version : Premiere Pro > Aide > À propos de Premiere Pro (Windows), et indiquez-la dans le rapport de diagnostic.

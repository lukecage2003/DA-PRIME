| Rôle | Famille | Fichiers statiques |
|---|---|---|
| Titres Signal | Anton | Regular |
| Voix Kiosque | Instrument Serif | Regular, Italic |
| Textes | Archivo | Regular, Medium, Bold, ExtraBold |
| Textes condensés | Archivo Condensed | Medium, Bold, ExtraBold |
| Rubriques, données | JetBrains Mono | Regular, Bold |

Archivo et JetBrains Mono sont des instances statiques tirées des polices variables officielles (`_variable/`, source Google Fonts) avec fontTools. Noms PostScript et empreintes : `fonts.json`. Installer uniquement les fichiers statiques sur un poste de travail : les polices variables de `_variable/` (web) portent les mêmes noms et créeraient des doublons.
